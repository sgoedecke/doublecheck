The paper incorrectly claims that supervised backpropagation will find good parameters whenever such parameters exist and the training data are sufficient. (minor, high confidence)
Tag
logical-error
Evidence type
counterexample
Location
Page 1, Introduction
Analysis
Existence of a good parameter setting does not imply that backpropagation can reach it. This is a concrete optimization failure, not merely an unsupported generalization, although it does not invalidate the paper's experiments.
Evidence
Consider the two-layer scalar network f(x)=w2w1x with squared loss on the single example x=1, y=1. Parameters w1=w2=1 achieve zero loss. At initialization w1=w2=0, however, both derivatives are zero: dL/dw1=2(w1w2-1)w2=0 and dL/dw2=2(w1w2-1)w1=0. Backpropagation therefore never leaves the zero-loss-gradient initialization and cannot find the existing solution, contradicting the statement that it 'will find these parameters.' The construction extends directly to arbitrarily wide deep linear networks initialized with zero layer matrices.
Paper details

Authors: Ilya Sutskever, Oriol Vinyals, Quoc V. Le

One demonstrable logical error appears in the introductory optimization claim; no concrete errors were found in the reported arithmetic or core sequence-to-sequence formulation.

AlphaZero is claimed to use no domain knowledge except game rules, but the Methods explicitly identify and use non-rule domain knowledge. (major, high confidence)
Tag
factual-error
Evidence type
direct-contradiction
Location
Abstract and conclusion; Methods, “Domain Knowledge,” items 1, 4, and 5
Analysis
The abstract says AlphaZero was given “no domain knowledge except the game rules.” However, the paper's own “Domain Knowledge” section lists additional inputs: an architecture matched to the board's grid structure, exploration-noise scaling based on the typical number of legal moves, and maximum game lengths determined from typical game length. The latter two are empirical domain statistics, not game rules. Because the paper itself classifies these items as domain knowledge, both statements cannot be true as written.
Evidence
The abstract restricts domain knowledge to game rules. Methods item 4 states, “The typical number of legal moves is used to scale the exploration noise,” and item 5 states that maximum steps were “determined by typical game length.” The section concludes that AlphaZero used no domain knowledge “beyond the points listed above,” expressly acknowledging those additional forms of domain knowledge.

Analysis
The lemma's bound fails even in one dimension with one timestep.
Evidence
Set T=d=1 and g_1=0.1, with valid bounds G=G_infinity=0.1. The claimed left side is sqrt(g_1^2)=0.1, while the right side is 2 G_infinity ||g_1||_2=2(0.1)(0.1)=0.02. Thus 0.1 <= 0.02 is false. Lemma 10.4 and the main regret proof subsequently invoke this lemma.
The regret proof incorrectly telescopes coefficients that need not be nonnegative. (major, high confidence)
Tag
mathematical-error
Evidence type
invalid-derivation
Location
Appendix, proof of Theorem 10.5, equations immediately before the bound beginning 'From the assumption'
Analysis
The proof replaces squared distances by their upper bound inside terms weighted by differences of sqrt(v_hat_t)/alpha_t. That replacement preserves an upper bound only when those differences are nonnegative, but Adam does not ensure this.
Evidence
Take beta_2=0.9, g_1=1, and g_2=0. Then v_hat_1=1 and v_hat_2=0.09/0.19=9/19. With alpha_t=alpha/sqrt(t), sqrt(v_hat_1)/alpha_1=1/alpha, whereas sqrt(v_hat_2)/alpha_2=sqrt(18/19)/alpha<1/alpha. The coefficient difference at t=2 is therefore negative. For a negative coefficient, replacing a squared distance x<=D^2 by D^2 reverses the required inequality, so the displayed regret bound does not follow.
The proof applies the iterate-distance assumption to the comparator theta-star without justification. (major, high confidence)
Tag
logical-error
Evidence type
invalid-derivation
Location
Theorem 10.5 and its proof, statement 'From the assumption, ||theta_t-theta-star||_2 <= D'
Analysis
The theorem assumes only that pairs of parameters generated by Adam are within D. The regret comparator theta-star is an arbitrary best fixed point in X and need not be a generated iterate.
Evidence
A sequence with every generated iterate equal to 0 satisfies the stated pairwise condition with D=0, while a comparator theta-star=1 has distance 1 from every iterate. Hence the proof's asserted implication does not follow from the theorem's assumptions.
